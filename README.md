# GitHub DeskNav

A simple Chrome extension that adds a floating navigation bar to GitHub, making navigation feel more convenient and familiar.

## Why GitHub DeskNav?

As someone who frequently uses GitHub, I found myself sometimes getting frustrated while navigating through repositories, issues, profiles, and different pages.

You might go from:

GitHub → Profile → Repository → Issues → Issue

and later want to return to a page you visited earlier.

GitHub DeskNav was built to make this experience simpler by providing quick navigation controls and a way to retrace your browsing journey.

## Features

- ← **Back** — Quickly go to the previous page.
- → **Forward** — Move forward in your browsing history.
- ⌂ **GitHub Home** — Return to GitHub's homepage.
- ▣ **Recent Pages** — View your recently visited GitHub pages.
- 🧭 **Browsing Journey** — See the sequence of pages you visited during your session.
- 🗑️ **Clear History** — Clear your saved recent pages or browsing journey.

## Browsing Journey

The Browsing Journey feature is one of the main ideas behind DeskNav.

Instead of only showing a list of recent pages, it keeps track of the path you followed.
